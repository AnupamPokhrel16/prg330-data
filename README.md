# Air Quality Data Analysis -- PRG-330 Final Project

Hourly air-quality analysis across six cities (Brasilia, Cairo, Dubai, London, New York, Sydney)
for all of 2024, built as the final project for PRG-330. The project walks through core Python
concepts -- variables, operators, loops, functions, file I/O -- before bringing in Pandas, NumPy,
and Matplotlib for the real 52,704-row analysis.

**Team:** Aishmita &middot; Aaska &middot; Anupam

## What's in this repo

| Path | What it is |
| :--- | :--- |
| `Air_Quality_Analysis.ipynb` | The full project: Module 0 (problem analysis), Modules 1-7, and Module 8 (conclusion), plus team contribution. Run this one top to bottom. |
| `Air_Quality.csv` | The dataset -- hourly readings of CO, CO2, NO2, SO2, O3, PM2.5, PM10, and AQI for each city. |
| `modules/` | The same 9 modules (0-8) split into individual notebooks, one per module, for standalone review (see below). |
| `Presentation.ipynb` | A stripped-down version for presenting live -- same modules and charts, without the academic framing. |
| `explain.ipynb` | A line-by-line walkthrough of every code cell (Modules 1-7): what it does, why it's written that way, and how the syntax works. |
| `file_io_summary.txt` | Generated by Module 5 each time the notebook runs -- not something to edit by hand. |

## Modules

0. **Problem analysis** -- objective, dataset description, and the problem statement the rest of the notebook answers
1. **Variables and data types** -- one real record pulled apart into individual variables
2. **Operators and conditional statements** -- arithmetic/comparison/logical/assignment operators, hand-written `if`/`elif`/`else` AQI classification
3. **Loops** -- `for`, conditional `for`, and `while` loops over a 12-record sample
4. **Functions** -- the Module 2/3 logic wrapped into reusable functions
5. **File I/O** -- reading the raw CSV with `open()`, writing and reading back a summary file
6. **Pandas + NumPy analysis** -- loading the full dataset, the missing-CO2 investigation, city/month summaries, NumPy arrays, threshold counts, and correlations
7. **Matplotlib visualization** -- four labeled charts built from Module 6's output
8. **Conclusion** -- summary, major findings with their deciding factors, a ranked conclusion analysis, and the final takeaway

The notebooks in `modules/` are extracted sections of the main notebook, not independently
runnable in every case: Modules 2-5 and 7 depend on variables or functions defined in an earlier
module, the same way the full notebook hands work from one section to the next. Modules 0, 1, 6,
and 8 are self-contained and can be run on their own.

## Running it

Requires Python 3.11+ with Jupyter, Pandas, NumPy, and Matplotlib. A virtual environment is
already set up in `.venv/`:

```bash
source .venv/bin/activate
jupyter notebook Air_Quality_Analysis.ipynb
```

Or run it end-to-end from the command line:

```bash
.venv/bin/jupyter nbconvert --to notebook --execute --inplace Air_Quality_Analysis.ipynb
```

If you're starting from scratch instead of using `.venv/`:

```bash
pip install jupyter pandas numpy matplotlib
```

## What we found

Dubai has by far the worst air quality of the six cities (AQI 85.1) and Brasilia the best (24.7).
AQI stays fairly steady across the year but peaks in July/August, and almost all of the dataset's
worst hours trace back to a single event in Dubai on 18 August 2024 rather than a general seasonal
trend. PM2.5 and PM10 both correlate strongly with AQI (r = 0.82 and r = 0.85). The full reasoning,
including the deciding factor behind each conclusion, is in the notebook's **Major Findings** and
**Conclusion Analysis** sections.
